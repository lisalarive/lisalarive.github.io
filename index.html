Note : 18,6/20

Application web de quiz interactif proposant plus de 27 000 questions générées automatiquement via l'API Gemini à partir de pages Wikipédia, réparties sur 6 thématiques et 3 niveaux de difficulté.

Python & FastAPI HTML/CSS/JS SQLite Gemini API Docker GitLab CI/CD
  • Architecture & Code : Structure découplée backend/frontend. Code systématiquement documenté (docstrings) et sécurisé par des tests unitaires.
  • Algorithme tolérant : Correcteur de réponses intelligent gérant la casse, les accents et les fautes de frappe (distance de Levenshtein).
  • Démarche UX : Conception sur Figma et itérations basées sur des tests utilisateurs pour aboutir au design final responsive.
  • Méthodologie : Développement structuré en appliquant les principes de gestion de projet (Agile, cycle en V).
